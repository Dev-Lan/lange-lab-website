# Notes on building this site

March 10, 2026 — Devin Lange

_This is a placeholder post._

This site is built with [VitePress](https://vitepress.dev/). The structure is
deliberately plain: every person, publication, and post is a single markdown
file, and each listing page reads the directory next to it at build time. There
is no database and no CMS.

The practical upshot is that editing the site is editing a text file. A lab
member who wants to update their profile edits one file and nothing else.
